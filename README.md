# Roaa Al-Lehyani Portfolio

A bilingual portfolio with one shared HTML structure and one unified layout system.

## Files
- `index.html`: shared English/Arabic markup
- `assets/styles.css`: all visual styles, including one authoritative header/footer system
- `assets/script.js`: language, theme, navigation, animations, and interactions
- `assets/Roaa_AlLehyani_Resume.pdf`: resume

The language switch updates `lang`, `dir`, translated content, and the mirrored layout without duplicated pages or competing CSS patches.


## Sharing and icons
- `assets/og-image.png`: 1200×630 social-sharing preview
- `assets/favicon.svg` and PNG/ICO variants: browser and device icons
- `site.webmanifest`: installable-site metadata
- `index.html`: Open Graph, Twitter Card, canonical, and JSON-LD metadata

The canonical and social-image URLs currently target `https://rlehyani.github.io/`. Update them if the final published domain is different.
